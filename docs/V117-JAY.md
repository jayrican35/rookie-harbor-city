# Jay: shared campaign and connected-world locomotion

The marina had its own officer sprite while the rest of the connected city used a block figure. Jay now enters one shared renderer before either legacy branch, independently of region. The original campaign registers the same renderer once with its existing priority dispatcher. Returning true stops older painters, so Jay is drawn once.

The master sheet supplies Jay's identity: spiky dark hair, beard, blue duty jacket, navy trousers, black boots, no cap. New transparent atlases contain four cardinal directions, eight walk frames and eight run frames; walk column zero supplies a planted idle pose. The small reference rows had inconsistent direction labels and seven visible walk poses; they were not pasted into the game as a background. Production frame preparation is offline. Cells share fixed head/foot anchors, and image decoding never introduces a different character.

Animation phase advances by actual collision-resolved distance. No movement means no cycling, and map changes/teleports reset the tracker. Connected movement uses normalized input, an analog deadzone, facing hysteresis and exponential acceleration integrated consistently at 30/60/120 Hz. RUN or Shift requests a faster gait; input is cleared on blur, hiding and exit. The campaign keeps its existing collisions and temporarily applies a run-speed multiplier, restoring the original speed even on exceptions.

This pass adds no canvas or requestAnimationFrame loop. The existing connected-world and campaign views are still separate. The build inserts a narrowly guarded suspension in the compiled campaign loop while the connected city is open, resetting the timing clock before return. The hidden campaign no longer simulates or draws underneath the connected canvas. The original game.js and outbreak.css remain byte-for-byte unchanged, and training/Academy/Zombie modes bypass Jay's new bridge.

Validation: shared renderer/tracker and bridge tests, actual connected-player input regression, existing campus/roads/marina/HUD/NPC suites, compiled-bundle syntax and single-registry checks. Browser QA covers original campaign, precinct grounds, marina, movement, running and mobile layouts. This remains the isolated game preview; main Site and original game root are unchanged.

Asset prompts: derive Jay's top views from the supplied animation master sheet; transparent 9x4 walk/idle grid and 8x4 run grid; rows down/left/right/up, consistent chibi proportions, actual alternating limb poses, no labels/scenery. Generated using the built-in image tool; normalized with tools/prepare_v117_jay.py. Production paths: published-game-capture/assets/jay-v117/jay-walk.webp and jay-run.webp. Manifest records exact hashes and dimensions.
