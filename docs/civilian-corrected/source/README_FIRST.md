## Art truthfulness — read before importing

The food vendor's 16 frames are **bit-for-bit identical to the pilot you approved**. The other 29 roles reuse the artist-rendered pilot walking anatomy, goggles, face, fingers, shoes, and directional poses, with modular costume colors, role badges, and category-specific headwear. This preserves the proven clean walking limbs rather than painting hand and leg repairs on top of them.

**The other 29 are not 29 independently hand-painted character turnarounds.** Costume details and vector-generated hats still warrant an artistic pass; compare the GIFs with your quality expectations before importing as final artwork. This is a functional, review-ready *working production-format pack* rather than a claim of finished bespoke artwork.

All work remained local. No game code was changed, no version numbers were modified, no GitHub push/deploy occurred and Zombie Outbreak remains untouched.
